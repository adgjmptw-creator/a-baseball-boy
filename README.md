# a-baseball-boy（野球フォームチェッカー）

おりこう🤖 な野球フォーム分析アプリ

## このアプリについて

**a-baseball-boy** は、お子さんの野球（投球・打撃）のフォームをかんたんに分析できる、ブラウザ内で動く無料アプリです。

### できること
- 📹 **フォーム撮影**: 投球または打撃の動画をアップロードしたり、その場で撮影したりできます
- 🧠 **自動分析**: ブラウザ内の AI（MediaPipe Pose）がお子さんの身体の動きを分析します
- ⭐ **子ども向け評価**: 足の上げ方、ひじの高さ、体の回転など、野球の基本を 1～5 個の★でまとめます
- 💡 **アドバイス**: 良かった点をほめ、工夫すると良い点を優しく提案。練習のコツも付けます
- 🔒 **プライバシー安心**: 動画・身体データは**スマホやパソコンの中だけで処理**。サーバーへは送りません

## 使い方

### 最初に
1. **ブラウザを開く**: Chrome・Edge・Safari の最新版（スマートフォン推奨）
2. **サイトにアクセス**: https://adgjmptw-creator.github.io/a-baseball-boy/
3. **カメラ許可を与える**: アプリが「カメラを使ってもいい？」と聞いたら「許可」をタップ
4. 初回は AI モデル（約 5～10 MB）を CDN から自動ダウンロード。しばらく待つと「さあ、はじめよう！」の画面が表示されます

### 撮影・アップロード方法

#### **「投球のフォームをえらぶ」または「打撃のフォームをえらぶ」**
- 📂 **どうがをえらぶ**: 以前撮った動画ファイル（MP4・MOV など）をアップロード
- 📽️ **いまからさつえい**: その場でスマホのカメラから 5～10 秒撮影

#### 撮影のコツ（保護者向け）
良い分析のためのポイント:

| コツ | なぜ？ |
|---|---|
| **横から撮影** | お子さんの体の前後の動き（ひじ、腰の回転など）が見える |
| **全身が映るように** | 足から頭までぜんぶ見えることが大事 |
| **明るい場所で** | 暗いと身体の関節が認識しにくくなります |
| **三脚やテーブルに固定** | ぶれると分析が難しくなります |
| **5～10 秒の動画** | あまり長いと処理に時間がかかります |

### 結果の見方
1. **★評価（1～5）**: フォームの総合評価。5 つ星がベスト
2. **ほめポイント**: 「ひじが高い」「頭が安定している」など良かった点
3. **アドバイス（最大 2 個）**: 工夫すると良い点と、その練習方法
4. **キーモーメント**: 投球なら「足上げ」「着地」「リリース」「フォロー」。打撃なら「かまえ」「トップ」「インパクト」「フィニッシュ」。タップするとそこまで動画が進みます

## 対応環境

### ブラウザ
- **Chrome/Edge**: 最新版（Android・Windows・Mac）
- **Safari**: 最新版（iPhone・iPad・Mac）
- 推奨: **モバイル（スマートフォン・タブレット）**

### データ容量
- 初回: AI モデル 5～10 MB を CDN からダウンロード（1 回だけ）
- その後: インターネット不要。オフラインでも使えます
- 動画ファイル: 端末に保存されません

### 注意
- `file://` プロトコル（ファイルをそのままブラウザで開く）では動きません。`http://` または `https://` で開いてください

## プライバシー・セキュリティ

### 送信されないもの
🔐 **すべてが端末内で処理されます**
- 撮影・アップロードした動画
- AI が解析した身体の骨格データ（ランドマーク）
- 分析結果
- お子さんの名前、年齢、その他の情報

### 外部通信
- ❌ サーバーなし。ローカルホストもなし
- ✅ **ライブラリとモデルの CDN から取得のみ**
  - MediaPipe（Google が提供する姿勢推定ライブラリ）
  - 動作に必須なファイル以外は通信しません

### 動画の取り扱い
- 動画は**スマホやパソコンのメモリ上だけで処理**
- 自動保存や、別の場所への転送はしません
- 保護者が「保存」をタップしない限り、ブラウザを閉じるか別のページに移ると、分析結果は消えます

詳しくは **[プライバシーポリシー](./docs/PRIVACY.md)** をご覧ください。

## ローカルで試す方法

開発者向け・テスト用:

```bash
# リポジトリをクローン
git clone https://github.com/adgjmptw-creator/a-baseball-boy.git
cd a-baseball-boy

# ローカルサーバーを起動
python3 -m http.server 8000
# または
npx http-server

# ブラウザで http://localhost:8000 を開く
```

⚠️ **注意**: `file://` プロトコルでは ES Modules が動きません。必ず `http://` で開いてください。
