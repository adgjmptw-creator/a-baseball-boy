# a-baseball-boy（野球フォームチェッカー）

おりこう🤖 な野球フォーム分析アプリ

## このアプリについて

**a-baseball-boy** は、お子さんの野球（投球・打撃）のフォームをかんたんに分析できる、ブラウザ内で動く無料アプリです。

### できること
- 📹 **フォーム撮影**: 投球または打撃の動画をアップロードしたり、その場で撮影したりできます
- 🧠 **自動分析**: ブラウザ内の AI（MediaPipe Pose）がお子さんの身体の動きを分析します
- ⭐ **子ども向け評価**: 足の上げ方、ひじの高さ、体の回転など、野球の基本を 1～5 個の★でまとめます
- 💡 **アドバイス**: 良かった点をほめ、工夫すると良い点を優しく提案。練習のコツも付けます
- 🔒 **プライバシー安心**: 動画・身体データは**スマホやパソコンの中だけで処理**。サーバーへは送りません

## 使い方

### 流れ
1. **ブラウザで開く**: Chrome・Edge・Safari の最新版（スマートフォン推奨）で https://adgjmptw-creator.github.io/a-baseball-boy/ を開くと、すぐに**ホーム**画面が出ます（カメラ許可は聞かれません）
2. **ホーム**: 「**なげる**（ピッチング）」か「**うつ**（バッティング）」をタップ
3. **動画を用意する**:
   - 📁 **どうがを えらぶ**: 撮りためた動画ファイルを選ぶ
   - 📷 **いまから さつえい**: その場で撮影（最長 15 秒）。**カメラの許可は、このボタンを押したときだけ**聞かれます。許可しなくても「どうがを えらぶ」は使えます
4. **かくにん**: 動画を見て、よければ「**これで かいせき**」（やり直すときは「とりなおす」）
5. **解析中**: 進み具合のバーと、骨格が動くプレビューが出ます。初回だけ AI モデル（約 5～10 MB）を CDN からダウンロードします
6. **結果**: ★評価・ほめポイント・アドバイスなどが出ます。うまく映っていないときは、やさしいメッセージで撮り直しをすすめます

#### 撮影のコツ（保護者向け）
良い分析のためのポイント:

| コツ | なぜ？ |
|---|---|
| **横から撮影** | お子さんの体の前後の動き（ひじ、腰の回転など）が見える |
| **全身が映るように** | 足から頭までぜんぶ見えることが大事 |
| **明るい場所で** | 暗いと身体の関節が認識しにくくなります |
| **三脚やテーブルに固定** | ぶれると分析が難しくなります |
| **短めの動画（15 秒くらいまで）** | 長いと処理に時間がかかります |

### 結果の見方
1. **★評価（1～5）と てん数**: フォームの総合評価。5 つ星がベスト
2. **よかったところ**: 「ひじが かたの たかさまで あがっている」など良かった点
3. **もっと よくなる ポイント（最大 2 個）**: 工夫すると良い点と、その練習方法
4. **つぎの もくひょう**: 次に意識する一言
5. **キーモーメント**: 投球は「足上げ」「着地」「リリース」「フォロー」、打撃は「かまえ」「トップ」「インパクト」「フィニッシュ」。サムネイルをタップすると、その場面を骨格つきで表示し、スライダーでコマおくりできます（動画の途中から始まっていて見つからない場面は出ません）
6. **くわしい けっか**: 各項目を ◎ すごい / ○ いいね / △ ねらおう で表示
7. **けっかを ほぞん**: 結果を画像（PNG）として端末にダウンロードします（どこにも送信されません）

## 対応環境

### ブラウザ
- **Chrome/Edge**: 最新版（Android・Windows・Mac）
- **Safari**: 最新版（iPhone・iPad・Mac）
- 推奨: **モバイル（スマートフォン・タブレット）**

### データ容量
- 初回: AI モデル 5～10 MB を CDN からダウンロード（1 回だけ）
- その後: インターネット不要。オフラインでも使えます
- 動画ファイル: 端末に保存されません

### 注意
- `file://` プロトコル（ファイルをそのままブラウザで開く）では動きません。`http://` または `https://` で開いてください

## プライバシー・セキュリティ

### 送信されないもの
🔐 **すべてが端末内で処理されます**
- 撮影・アップロードした動画
- AI が解析した身体の骨格データ（ランドマーク）
- 分析結果
- お子さんの名前、年齢、その他の情報

### 外部通信
- ❌ サーバーなし。ローカルホストもなし
- ✅ **ライブラリとモデルの CDN から取得のみ**
  - MediaPipe（Google が提供する姿勢推定ライブラリ）
  - 動作に必須なファイル以外は通信しません

### 動画の取り扱い
- 動画は**スマホやパソコンのメモリ上だけで処理**
- 自動保存や、別の場所への転送はしません
- 保護者が「保存」をタップしない限り、ブラウザを閉じるか別のページに移ると、分析結果は消えます

詳しくは **[プライバシーポリシー](./docs/PRIVACY.md)** をご覧ください。

## ローカルで試す方法

開発者向け・テスト用:

```bash
# リポジトリをクローン
git clone https://github.com/adgjmptw-creator/a-baseball-boy.git
cd a-baseball-boy

# ローカルサーバーを起動
python3 -m http.server 8000
# または
npx http-server

# ブラウザで http://localhost:8000 を開く
```

⚠️ **注意**: `file://` プロトコルでは ES Modules が動きません。必ず `http://` で開いてください。

## GitHub Pages への公開方法

デプロイは GitHub Actions（[`.github/workflows/pages.yml`](./.github/workflows/pages.yml)）が行います。
**初回だけ** リポジトリの設定で Pages を有効にしてください（Actions の権限では自動で有効化できません）。

1. GitHub のリポジトリページで **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブで「Deploy to GitHub Pages」を **Run workflow** で手動実行する（または何かを push する）
4. 数十秒後に https://adgjmptw-creator.github.io/a-baseball-boy/ で公開されます

以後は `main` ブランチ（および初回公開用の作業ブランチ）への push で自動的に再デプロイされます。
