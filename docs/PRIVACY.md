# プライバシーポリシー

**a-baseball-boy（野球フォームチェッカー）**のデータ取り扱いについて、保護者・ユーザーの皆さまへ。

## 1 行でいうと

🔒 **すべてが端末の中だけで処理されます。サーバーに送られません。**

## データフロー図

```
┌─────────────────────────────────────────────────────────────┐
│ あなたのスマートフォン・パソコン                           │
│                                                             │
│  ① 動画をアップロード                                      │
│     または撮影                                              │
│          │                                                  │
│          ↓                                                  │
│  ② ブラウザが MediaPipe (AI) で                            │
│     骨格データを抽出                                        │
│          │                                                  │
│          ↓                                                  │
│  ③ 分析結果を計算                                          │
│     & 表示                                                  │
│                                                             │
│  ✅ ここまで、すべて端末内                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘

※ ③ のデータがサーバーに送られることはありません。
```

## 何が送られる？何が送られない？

### ❌ 外部に送られないもの

- 動画ファイル
- 骨格データ（ランドマーク）
- 分析結果
- ユーザー ID・名前・年齢などの個人情報

### ✅ 外部から取得されるもの（初回のみ）

ブラウザの動作に必須なライブラリだけ、CDN から自動ダウンロード:

- **MediaPipe Vision Bundle** (`vision_bundle.mjs`)
  - 提供元: [jsdelivr](https://www.jsdelivr.net)
  - 用途: 姿勢推定のコアライブラリ
- **モデルファイル** (`pose_landmarker_lite.task`)
  - 提供元: Google Cloud Storage（公開）
  - 用途: AI の脳（骨格認識）

**それ以外の通信はありません。**

## カメラ許可について

### 「カメラを使ってもいい？」と聞かれたら

ブラウザが以下のため**だけに**カメラにアクセスします:

- リアルタイム撮影（「いまからさつえい」ボタン）
- 動画ファイルのプレビュー表示

✅ 撮影した動画は端末のメモリに一時保存されます。  
❌ クラウド自動保存や他人への共有はしません。

### カメラを使わない場合

- 「どうがをえらぶ」でアップロードすれば、カメラ許可は不要

## 動画の取り扱い注意

### ✅ 安全な使い方

- お子さんが特定されない範囲での撮影
- 背景に他人（兄弟姉妹など）が映らないようにする
- 学校のロゴ・ユニフォーム番号など個人を特定する情報は避ける

### ❌ 避けるべき撮影

- お子さんの顔がはっきり映る（アップで撮影しない）
- 学校・団体の名前が見える
- 他のお子さんが映っている

## よくある質問（FAQ）

**Q: 分析結果を他の人と共有できますか？**

A: ブラウザ内のスクリーンショット機能で保存・共有できます。サーバーへの自動共有はありません。

**Q: 動画は保存されますか？**

A: ブラウザを閉じるまで、メモリ上に一時保存されます。端末のストレージに自動保存はしません。ユーザーが「保存」をタップした場合のみ、端末に保存されます。

**Q: オフラインで使えますか？**

A: 初回はモデルをダウンロードしますが、その後はインターネット接続なしで使えます。

**Q: 子どもの安全について、何か心配することはありますか？**

A: このアプリはデータを外部に送信しないため、**お子さんの情報が漏洩する心配はありません**。ただし、撮影の際は顔や個人情報が映らないようにご注意ください。
